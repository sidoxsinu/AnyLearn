# Modern Web Guidance (Local Skill Copy)

Source: /Users/sinanm/.gemini/config/plugins/modern-web-guidance-plugin/skills/modern-web-guidance/SKILL.md

Modern web development best practices:
- Responsive design: container queries, flex/grid, mobile-first with desktop scaling.
- Semantic HTML and accessibility: explicit `aria-label`, visible focus rings (`focus-visible:outline-none focus-visible:ring-2`), high color contrast.
- Performance: lightweight CSS, no heavy runtime overhead, CSS scrollbars, smooth transitions.
- Modern CSS features: CSS variables, `@theme`, backdrop-filter for floating toolbars, SVG curves for notch integration.
